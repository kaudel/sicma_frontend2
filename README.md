# sicma_frontend2

Sicma frontend typescript

How to run the project

Install Vitejs:
https://vite.dev/

verify if node.js is installed:

`node -v`

`npm -v `

download app or clone it using git:

`git clone git@github.com:kaudel/sicma_frontend2.git`

In the project directory, restore the node modules:
`npm install`

Execute app:

`npm run dev`
